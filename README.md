# 🎬 Hybrid Movie Recommendation System

A web-based movie recommender system that combines **Content-Based Filtering** (using TF-IDF and Cosine Similarity) with **Collaborative Filtering** techniques to suggest top movie recommendations based on user-selected input. Built using **Streamlit** and integrated with **TMDB API** for real-time poster fetching.

---

## 📌 Features

- 🔍 Get top 5 movie recommendations based on your selected movie.
- 🧠 Uses a hybrid model of **TF-IDF vectorization** and **cosine similarity** for better suggestions.
- 🎨 Displays real-time **movie posters** using TMDB API.
- 📈 Shows **ratings** and **vote counts** for informed viewing decisions.
- 💻 Built with **Streamlit** for a fast, interactive web interface.

---

## 🛠️ Tech Stack

| Layer               | Tools & Libraries                             |
|---------------------|-----------------------------------------------|
| Frontend            | Streamlit                                     |
| Backend             | Python (Pandas, Scikit-learn, Requests)       |
| Data Storage        | CSV Files (`movie.csv`, `rating.csv`)         |
| ML / Recommendation | TF-IDF Vectorizer, Cosine Similarity          |
| API Integration     | TMDB (The Movie Database) API                 |
